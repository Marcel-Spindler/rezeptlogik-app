EINFACHSTE VARIANTE (Excel) ⭐

  1. Öffne KW19_Analyse_Excel_Report.xlsx
  2. Doppelklick → Excel öffnet automatisch
  3. Blätter durchblättern → Alle 4 Sheets anschauen
  4. Graphiken & Tabellen → Alles farblich geordnet

DETAILLIERTE VARIANTE (CSV)

  1. Öffne KW19_Analyse_Erweitert_Zugaenge_Bewegungen.csv
  2. Rechtsklick → Öffnen mit → Excel
  3. Nach Produkt filtern → Top Row "Filter"
  4. Spalten sortieren → Nach Gewicht, Bereich, etc.
  5. Pro Bereich sehen:
    • Zugänge_BEREICH = Was reinkam (+)
    • Bewegungen_BEREICH = Was rausgegangen ist (-)
    • Netto_BEREICH = Aktueller Saldo

INTERAKTIVE VARIANTE (Jupyter)

  1. Öffne KW19_Analyse.ipynb
  2. Mit VS Code öffnen (automatisch)
  3. Zellen einzeln ausführen → Play-Button (▶)
  4. Live-Graphen → Charts direkt im Notebook
  5. Code ändern → Beliebige Analysen anpassen
💡 TIPP: Starten Sie mit Option 1 (Excel Report)! Das ist am schnellsten und alle Daten sind übersichtlich dargestellt.
