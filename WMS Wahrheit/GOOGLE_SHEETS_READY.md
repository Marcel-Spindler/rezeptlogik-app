## 💡 GOOGLE SHEETS TIPPS

### Filter setzen (beste Funktion!)
```
Daten → Filter → Auf jeder Spalte Filter-Icon
→ Nach Produkt/Bereich/Gewicht filtern
```

### Sortieren
```
Spalte anklicken → Rechtsklick → Sortierung wählen
→ A-Z, Z-A, oder nach Zahl (klein → groß)
```

### Bedingte Formatierung (Farbcodes)
```
Daten markieren → Format → Bedingte Formatierung
→ Positive = Grün, Negative = Rot, etc.
```

### Pivot-Tabelle (Zusammenfassungen)
```
Daten → Pivot-Tabelle → Automatische Analyse
→ Groupieren & Summieren nach beliebigen Kriterien
```

### Formeln & Berechnungen
```
Zelle klicken → =SUM(), =AVERAGE(), =COUNTIF()
→ Excel-artige Funktionen möglich
```

## ❓ HÄUFIGE FRAGEN

**F: Ist TSV besser als CSV?**
A: Ja für Google Sheets! TSV = Tab-Separated Values, besser mit Umlauten (ö, ä, ü)

**F: Kann ich mehrere TSV-Dateien kombinieren?**
A: Ja! Jede als separates Sheet importieren → Dann zu Tabs verbinden

**F: Funktioniert auch mit Excel?**
A: Ja! Nutze KW19_Analyse_Excel_Report.xlsx oder lade als Sheet-ZIP herunter

**F: Wie oft kann ich Daten aktualisieren?**
A: Beliebig oft! Alte Datei löschen → Neue Datei importieren

**F: Können andere das bearbeiten?**
A: Nur wenn du "Bearbeitung" erlaubst. "Ansicht" = Nur anschauen

**F: Gibt es Limits?**
A: Google Sheets: Bis 10 Mio. Zellen pro Sheet. Deine Daten sind viel kleiner ✓
