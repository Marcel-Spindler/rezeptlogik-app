🚀 So teilst du es (3 Schritte)

1 Google Sheets öffnen

  1. Gehe zu https://sheets.google.com
  2. Melde dich mit deinem Google-Konto an
  3. Klick auf '+' (Neue Tabelle)

2 Dateien importieren

  1. Klick oben links auf Datei → Importieren
  2. Wähle 'Datei hochladen' Tab
  3. Lade eine TSV-Datei hoch (z.B. KW19_Google_Sheets_PRODUKTE.tsv)
  4. Google erkennt automatisch Tab-Trennzeichen ✓
  5. Klick 'In neue Tabelle importieren'
  6. Fertig! (für jede andere Datei wiederholen)

3 Teilen & Freigeben

  1. Öffne die importierte Tabelle
  2. Klick oben rechts auf 'Freigabe' (oder 🔗)
  3. Wähle: Einige Personen oder Jeder mit dem Link
  4. Berechtigungen setzen:
    • Ansicht = nur ansehen (sicher)
    • Bearbeitung = ändern dürfen
    • Kommentierung = mit Kommentaren
  5. Link kopieren & verteilen 📧

📧 Teilen-Methoden

🔗 Via Link (Empfohlen)

Beste Methode für schnelle Freigabe:

Nach Import → Klick "Freigabe" → "Jeder mit dem Link kann zugreifen" → Link kopieren → Per E-Mail/Chat versenden

Vorteil: Keine Einladung nötig, sofort Zugriff

👥 Mit Personen teilen

Für gezielten Zugriff:

Freigabe → "Einige Personen" → E-Mail-Adressen eingeben → Berechtigungen wählen → Freigeben

Vorteil: Nur bestimmte Personen haben Zugriff

📥 Download für Offline

Wenn Offline nötig:

Nach Import → Datei → Herunterladen → Format wählen (Excel, PDF, CSV, TSV)

Vorteil: Offline verfügbar, aber keine Live-Updates

💡 Google Sheets Tips & Tricks

✅ Empfohlen MACHEN:

  • ✓ TSV statt CSV (bessere Umlaute)
  • ✓ Filter verwenden (Daten → Filter)
  • ✓ Spalten sortieren (A-Z, Z-A)
  • ✓ Bedingte Formatierung für Farben
  • ✓ Pivot-Tabellen erstellen
  • ✓ Link mit "Ansicht" Berechtigung teilen
  • ✓ Benachrichtigungen aktivieren

❌ Vermeiden:

  • ✗ Direkt Rohdaten ändern (Backup machen)
  • ✗ Zu viele Berechtigungen vergeben
  • ✗ Sensible Daten ohne Link-Schutz teilen
  • ✗ Auf riesige Dateien direkt hochladen
  • ✗ Ohne Versionsverlauf arbeiten
  • ✗ Offline ohne Sync
  • ✗ Falsches Trennzeichen beim Import

🔒 Datenschutz & Sicherheit

⚠️ Bedenke:
  • Verzeichnis vs. Bearbeiten: "Ansicht" ist sicherer!
  • Link-Schutz: "Jeder mit Link" kann zugreifen → nur für vertrauenswürdige

❓ Häufige Fragen

F: Funktioniert TSV auch mit Google Sheets?

A: Ja! TSV (Tab-Separated Values) funktioniert sogar besser als CSV, besonders mit Umlauten (ö, ä, ü). Google erkennt automatisch Tab-Trennzeichen.

F: Kann ich mehrere Dateien in 1 Spreadsheet importieren?

A: Ja! Jede TSV-Datei = 1 neues Sheet. So hast du alle Daten an einem Ort (Übersicht, Produkte, Bereiche, etc.)

F: Wie teile ich mit automatischen Updates?

A: Google Sheets hat keine "Live"-Updates von CSV. Aber: Immer die TSV-Datei neu importieren = aktuellste Daten.

F: Wer soll Zugriff haben?

A: "Ansicht" = Nur ansehen (sicher). "Bearbeitung" = Ändern dürfen. Wähle je nach Zweck!

F: Kann ich die Daten auch in Excel teilen?

A: Ja! Nutze KW19_Analyse_Excel_Report.xlsx oder speichere aus Sheets als Excel herunter.
