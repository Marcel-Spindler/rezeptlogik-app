## Context

- `currentHfWeekLocal()` gibt korrekt `2026-W36` zurück (verifiziert via Node.js)
- Das Problem: React-State `selectedWeek` wird bei HMR konserviert und nie aktiv zurückgesetzt
- `allWmsWeeks` wird via `useMemo([], [])` nur einmal berechnet — wird nie aktualisiert wenn der Tab lange offen bleibt
- Es gibt keine Persistenz (kein localStorage/URL), aber auch keinen Mechanismus der zum aktuellen Datum zurückspringt

## Implementation Steps

### 1. `allWmsWeeks` reaktiv auf Sichtbarkeit machen
In `WmsKwOverviewView.tsx`: `allWmsWeeks` als State mit einem `visibilitychange`-Listener, der bei Tab-Focus die Liste neu generiert:

```ts
const [allWmsWeeks, setAllWmsWeeks] = useState(() => generateWmsWeeks(2026, 1));

useEffect(() => {
  const handler = () => {
    if (document.visibilityState === "visible") {
      const fresh = generateWmsWeeks(2026, 1);
      setAllWmsWeeks(prev => prev.length === fresh.length ? prev : fresh);
    }
  };
  document.addEventListener("visibilitychange", handler);
  return () => document.removeEventListener("visibilitychange", handler);
}, []);
```

### 2. `selectedWeek` automatisch auf aktuelle Woche setzen wenn veraltet
Beim `visibilitychange` oder Mount prüfen, ob `selectedWeek` noch die letzte verfügbare Woche ist. Wenn nicht (und der User nicht manuell gewechselt hat), auto-reset:

```ts
const [userManuallySelected, setUserManuallySelected] = useState(false);

// Im visibilitychange-Handler:
if (!userManuallySelected) {
  const currentWeek = fresh[fresh.length - 1];
  setSelectedWeek(currentWeek);
}
```

Im `onChange` des Dropdowns: `setUserManuallySelected(true)`.

### 3. "Aktuelle KW" Button neben dem Dropdown
Ein kleiner Button "↺ Heute" der immer zur aktuellen KW springt und `userManuallySelected` zurücksetzt.

### 4. Warnung bei alter Woche
Wenn `selectedWeek` nicht die letzte in `allWmsWeeks` ist, ein kleines gelbes Badge anzeigen: "⚠ Zeigt historische Daten (KW 17)"

## Verification

- Hard Refresh → Dropdown zeigt W36
- Manuell W17 wählen → Warnung erscheint, "↺ Heute" Button sichtbar
- Tab wechseln und zurück → wenn nicht manuell gewählt, springt automatisch zur aktuellen Woche
- Code-Änderung speichern (HMR) → Zustand bleibt nicht auf alter Woche hängen
