## Kontext

Die `WmsKwOverviewView` ist aktuell ein vertikaler Scroll-Stack mit ~4000 Zeilen. Daneben existiert `WmsLiveView` (4253 Zeilen) mit echtem Command-Center-Ansatz (Risk-Scoring, Recipe-Level-Tracking, Tabs). Das Projekt hat außerdem Production Planning, Line Planning, Kitchen Priority und Equipment-Daten.

**Ziel:** Die WMS-Übersicht in eine richtige **Kommandozentrale** verwandeln mit:
- Prominentem Status-Dashboard oben
- Tab-Navigation statt Endlos-Scroll
- Echtzeit-Situationsbewertung
- Engpass-Alerts und Yield-Alarme immer sichtbar
- Klare Priorisierung: was brennt, was läuft, was ist OK

## Implementation Steps

### 1. Neues Layout: Header-Bar + Alert-Strip + Tab-Navigation + Content

**Vorher:** `space-y-3` → Header → KPIs → Alerts → Bilanz → 7 SectionCards untereinander  
**Nachher:**
```
┌─────────────────────────────────────────────────────────┐
│ HEADER: "WMS Kommandozentrale · VF"  [KW▼] [⏺LIVE] [🔍]│
├─────────────────────────────────────────────────────────┤
│ ALERT STRIP (MHD + Yield, kompakt, dismissable)          │
├─────────────────────────────────────────────────────────┤
│ KPI BAR: 7 Tiles nebeneinander (immer sichtbar)          │
├──────┬──────────────────────────────────────────────────┤
│ TABS │ Leitwarte│Bilanz│Inbound│WO│Staging│Debox│PB│Plt│Sl│
├──────┴──────────────────────────────────────────────────┤
│ TAB CONTENT (nur aktiver Tab gerendert)                   │
└─────────────────────────────────────────────────────────┘
```

### 2. Neuer "Leitwarte"-Tab (Command Center Tab)

Der erste und wichtigste Tab — zeigt die **Gesamtsituation** auf einen Blick:

- **Ampel-Übersicht** pro Station: grün/gelb/rot basierend auf Coverage-Durchschnitt
- **Engpass-Liste**: Top 5 `detectKettenbruch` results mit Severity-Badges
- **Yield-Loss Top 5**: SKUs mit höchstem Verlust (aus YieldAlertBanner-Logik)
- **WO-Readiness-Score**: Gesamtdurchschnitt + worst-5 WOs
- **Aktiver Mengenstrom**: horizontale Flow-Grafik mit Summen pro Station (Inbound → ... → Sleeving)
- **MHD-Countdown**: kritischste 5 Items mit Ablaufdatum

### 3. Tab-System implementieren

Neuer State: `activeTab` mit Werten:
`"command" | "bilanz" | "inbound" | "workorders" | "staging" | "debox" | "postblast" | "plating" | "sleeving"`

Jede Station wird nur gerendert wenn ihr Tab aktiv ist (statt alle 7 gleichzeitig). Der "command"-Tab zeigt das neue Dashboard.

### 4. Header aufwerten → Sticky Command Bar

- `sticky top-0 z-40` mit Backdrop-Blur
- Station-Badges im Header werden klickbar → Tab-Wechsel
- Live-Mode Badge pulsiert grün
- Search bar mit `Cmd+K` Shortcut

### 5. Schnellaktionen im Leitwarte-Tab

- **"Trace" Quick-Buttons** für die problematischsten SKUs (klick → Trace öffnet)
- **WO-Detail-Direktlinks** für WOs mit niedrigster Readiness
- **Snapshot-Vergleich Mini-Chart**: Delta zum letzten Snapshot als Sparkline

### 6. Station-Tabs: Kompaktere Darstellung

- Badge im Tab zeigt Count + Farb-Indikator (rot wenn Engpass)
- Station-Content bleibt wie bisher (SectionCard Inhalt)
- Jeder Tab bekommt oben eine "Station KPI Mini-Bar" (Gesamt-Qty, SKU-Count, ältestes MHD, Engpass-Count)

### 7. Bilanz-Tab aufwerten

- Bleibt wie `StationsBilanz` aber mit prominenterem Gap-Breakdown-Display
- `gapBreakdown` wird in der Expansion jetzt als mini-Balkendiagramm visualisiert
- Filter-Buttons werden größer und prominenter

### 8. Visual Polish: Dark Header, Compact Design

- Header-Bar: `bg-slate-900 text-white` statt weißer Card
- Tabs: minimalistisch, aktiver Tab unterstrichen
- Content-Bereich: volle Breite ausnutzen, kein extra Card-Wrapping
