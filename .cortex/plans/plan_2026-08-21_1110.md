## Erweiterung: `ketEquipmentSummary.ts` → Vollständiger Stations-Ressourcen-Plan

Die bestehende Datei wird zu einem **kompletten Stations-Ressourcen-Aggregat** umgebaut. Alles was wir berechnen können, rein — gruppiert nach Stationen (PROCESS_ORDER), aufgeteilt in Run 1 (70%) und Run 2 (30%).

### Was wird pro Station aggregiert

| Ressource | Quelle in `BatchCalc` | Berechenbar |
|---|---|---|
| **Batches** | `equipBatches[].batches` | direkt |
| **kg Durchsatz** | `equipBatches[].perBatchKg × batches` | direkt |
| **GN-Bleche (Trays)** | `gnTraySummary[]` + components | direkt summierbar |
| **Wannen** | `totalKg / wanneKg` (CapacityDB) | über Zutaten berechenbar |
| **Ofen-Ladungen (Racks)** | `trays / ovenCap` (CapacityDB) | aus GN-Trays + oven-Cap |
| **Scoops benötigt** | `scoopInfo` (type+color) | direkt (Sammlung welche Scoops gebraucht werden) |
| **geschätzte Zeit (min)** | `batches × minutesPerBatch` | direkt |
| **WO-Nummern** | | direkt |
| **Allergene an der Station** | `allergensContains[]` | direkt (HACCP-relevant: welche Station hat Allergen-Kontakt) |

### Neue Typen (ersetzen/erweitern bestehende)

```ts
interface StationDemand {
  station: string;           // "BRAISER", "OVEN", "VEGGIE DEBOX", ...
  label: string;
  totalBatches: number;
  totalKg: number;
  estimatedMinutes: number;
  gnTrays: { gnType: string; count: number }[];  // Summierte GN-Bleche an dieser Station
  wannen: number;            // Gesamtwannen (kg ÷ wanneKg)
  ovenLoads: number | null;  // Nur für OVEN: Rack-Ladungen
  scoopsNeeded: ScoopEntry[];  // Welche Scoops diese Station braucht
  allergensPresent: string[];  // HACCP: welche Allergene an dieser Station
  woNumbers: string[];
}

interface ScoopEntry {
  methodType: string;    // "SCOOP", "LADLE", etc.
  methodColor: string;   // "grey", "blue", etc.
  yieldGrams: number | null;
  count: number;         // Wie viele WOs diesen Scoop brauchen
}

interface RunDemand {
  run: 1 | 2;
  runSharePct: number;   // 70 / 30
  date: string;
  shift: string;
  shiftLabel: string;
  stations: StationDemand[];
  totalKg: number;
  totalWos: number;
  totalGnTrays: number;  // Gesamtbleche über alle Stationen
  totalWannen: number;
}

interface FullResourceSummary {
  byRunDayShift: RunDemand[];
  stationPeaks: StationPeakInfo[];  // höchste Belastung je Station
  bottlenecks: BottleneckWarning[];
  scoopInventory: ScoopEntry[];     // Alle benötigten Scoops der Woche
  allergenStationMap: { station: string; allergens: string[] }[];  // HACCP-Übersicht
}
```
